---

## About Git Flow in This Project

This project uses **Git Flow** as the branching model to streamline feature development, releases, and hotfixes.

**Git Flow** is a branching strategy that provides a robust framework for managing releases and features by organizing branches into:

- `main` (or `master`): Production-ready code.
- `develop`: Integration branch for features; contains the latest development changes.
- `feature/*`: Branches for new features, branched off from `develop`.
- `release/*`: Branches to prepare for a release, branched off from `develop`.
- `hotfix/*`: Branches to quickly patch production issues, branched off from `main`.
